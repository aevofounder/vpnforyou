# Дизайн VPNforYou

Минималистичный нативный вид macOS: системный шрифт, мягкий светлый фон, тонкие разделители, один акцентный цвет.
Цифры (IP, скорость, пинг) набраны моноширинным шрифтом с табличными цифрами, чтобы не прыгали при обновлении.

Интерактивный макет всех экранов собран на холсте в Claude. Ниже то, что нужно для вёрстки в SwiftUI.

## Экраны

| Экран | Что на нём |
|---|---|
| **Окно в строке меню** (360 pt) | Статус и большой переключатель VPN, текущий сервер, карточка IP «Без VPN / Сейчас» с отметкой «IP сменился» и кнопкой скрытия, скорость сейчас с мини-графиком, быстрые ползунки для закреплённых программ |
| **Выбор сервера** | Поиск, сортировка (по пингу / по названию / избранные), список с кодом страны, протоколом, пингом и индикатором качества, звёздочка «в избранное», кнопка «Проверить пинг» |
| **Тест скорости** | Маршрут «Через VPN / Напрямую», пинг, загрузка, отдача с полосой прогресса, история последних тестов, сколько трафика расходует тест |
| **Приложения** (окно) | Режим «только выбранные / все, кроме выбранных», поиск, фильтр, список программ с путём, итоговым маршрутом (VPN / Напрямую) и ползунком, пометка «работает неточно» для Safari |
| **Активность** (окно) | Сводка: сколько программ идёт через VPN и напрямую, число соединений; таблица «программа → путь → куда → скорость», пауза обновления |
| **Настройки** (окно) | Внешний вид (кастомизация) и Основное |

## Кастомизация

- **Тема:** светлая, тёмная, как в системе.
- **Акцентный цвет:** 6 вариантов (ниже). Красит переключатели, графики, выбранный сервер, метки «VPN».
- **Иконка в строке меню:** щит, точка, код страны, скорость. Рядом можно показывать страну, скорость и время подключения.
- **Плотность:** просторно / компактно.
- **Карточки в окне:** порядок и видимость (подключение всегда первое и не скрывается).
- **Скрывать IP-адреса:** `203.0.•••.•••`, удобно при демонстрации экрана.
- **Звук при подключении**, **уведомление о смене IP**.

## Шрифт и размеры

- Текст: системный (SF Pro), 13 pt; заголовок статуса 20 pt semibold; метки секций 11 pt semibold, прописные.
- Цифры: SF Mono, табличные цифры (`.monospacedDigit()` / `.monospaced()`).
- Скругления: окно 14, карточки 12, кнопки и сегменты 8–10, чипы 6.
- Отступы: шаг 4 pt; внутри карточки 14 (компактно 10), между карточками 10 (компактно 6).
- Кликабельные строки не ниже 44 pt.

## Движение

- Нажатие: лёгкое уменьшение до 97 %, 140 мс.
- Переключатели: 160 мс, кривая `cubic-bezier(0.23, 1, 0.32, 1)` (быстрый старт, мягкая остановка).
- Подключение: точка статуса мягко пульсирует, пока идёт соединение.
- Окно из строки меню открывается без анимации: им пользуются десятки раз в день.
- При «Уменьшить движение» в системе все анимации отключаются.

## Данные на макете

Все IP-адреса на макете взяты из тестовых диапазонов (`198.51.100.0/24`, `203.0.113.0/24`), пинг и скорость условные.
