# Дизайн VPNforYou

Минималистичный нативный вид macOS в духе Liquid Glass: окно из строки меню — стеклянная панель,
поверх неё лёгкие полупрозрачные карточки, круглые «таблеточные» кнопки, один акцентный цвет.
Цифры (IP, скорость, пинг) набраны моноширинным шрифтом с табличными цифрами, чтобы не прыгали при обновлении.

Интерактивный макет всех экранов собран на холсте в Claude. Ниже то, что нужно для вёрстки в SwiftUI.

## Liquid Glass

Liquid Glass — системный материал macOS 26 Tahoe. Приложение поддерживает macOS 14+, поэтому:

| Система | Что видно |
|---|---|
| macOS 26 Tahoe | настоящий Liquid Glass: `.glassEffect(...)`, `.buttonStyle(.glass)` |
| macOS 14–15 | системное матовое стекло (`.ultraThinMaterial` / `.thinMaterial`) с тонкой светлой кромкой |

Правила:

- **Стекло — для «плавающего» слоя:** окно из строки меню, «пилюля» статуса, иконки-кнопки, панели инструментов.
  Контентные карточки внутри окна — не стекло, а лёгкая полупрозрачная заливка (стекло на стекле Apple не рекомендует).
- **Окна** («Приложения», «Активность», «Настройки») — непрозрачный фон, стеклянная панель сверху и боковая панель.
- Пользователь выбирает материал: **Liquid Glass / Матовое стекло / Сплошной** (для слабых Mac и любителей контраста),
  плюс ползунок прозрачности.
- При «Уменьшить прозрачность» в системе приложение само переходит на сплошной материал.

## Экраны

| Экран | Что на нём |
|---|---|
| **Окно в строке меню** (360 pt) | «Пилюля» статуса, ⌘K, большой переключатель VPN, линия маршрута, текущий сервер, IP «было → стало» с отметкой «IP сменился», скорость с мини-графиком, плитки быстрых настроек, быстрые ползунки программ |
| **Выбор сервера** | Поиск, «Самый быстрый», сортировка (по пингу / по имени / избранные), каждый регион — отдельная плитка с кодом страны, протоколом, пингом и индикатором качества, звёздочка «в избранное», «Проверить пинг» |
| **Тест скорости** | Маршрут «Через VPN / Напрямую», пинг, загрузка, отдача с полосой прогресса, история, сколько трафика расходует тест |
| **Приложения** (окно) | Режим «только выбранные / все, кроме выбранных», поиск, фильтр, список программ с путём, итоговым маршрутом (VPN / Напрямую) и ползунком, пометка «работает неточно» для Safari, уведомление с «Отменить» |
| **Активность** (окно) | Сводка: сколько программ идёт через VPN и напрямую, число соединений; таблица «программа → путь → куда → скорость», пауза |
| **Настройки** (окно) | Внешний вид (кастомизация) и Основное |

## Кастомизация

- **Материал:** Liquid Glass, матовое стекло, сплошной; ползунок прозрачности; живой предпросмотр.
- **Тема:** светлая, тёмная, как в системе.
- **Акцентный цвет:** 6 вариантов (ниже). Красит переключатели, графики, выбранный сервер, метки «VPN».
- **Иконка в строке меню:** щит, точка, код страны, скорость. Рядом можно показывать страну, скорость и время подключения.
- **Плотность:** просторно / компактно.
- **Карточки в окне:** порядок и видимость (подключение всегда первое и не скрывается).
- **Скрывать IP-адреса:** `203.0.•••.•••`, удобно при демонстрации экрана.
- **Ключ из буфера обмена**, **звук при подключении**, **уведомление о смене IP**.

## Шрифт и размеры

- Текст: системный (SF Pro), 13 pt; заголовок статуса 22 pt semibold; метки секций 11 pt semibold, прописные.
- Цифры: SF Mono, табличные цифры (`.monospacedDigit()` / `.monospaced()`).
- Скругления: окно 22, карточки 14, кнопки, сегменты, метки — полностью круглые («таблетки»), чипы стран 6.
- Отступы: шаг 4 pt; внутри карточки 14 (компактно 10), между карточками 8–10 (компактно 6).
- Кликабельные строки не ниже 44 pt.

## Движение

- Нажатие: лёгкое уменьшение до 97 %, 140 мс.
- Переключатели: 160–180 мс, кривая `cubic-bezier(0.23, 1, 0.32, 1)` (быстрый старт, мягкая остановка).
- Бегунок сегментов скользит за 220–240 мс, кривая `cubic-bezier(0.77, 0, 0.175, 1)`.
- Уведомление появляется снизу за 200 мс и само исчезает через 4 с.
- Подключение: точка статуса мягко пульсирует; по линии маршрута бежит точка, пока VPN включён.
- Окно из строки меню и палитра ⌘K открываются без анимации: ими пользуются десятки раз в день.
- При «Уменьшить движение» в системе все анимации отключаются.

## Данные на макете

Все IP-адреса на макете взяты из тестовых диапазонов (`198.51.100.0/24`, `203.0.113.0/24`), пинг и скорость условные.
