# VPNforYou

VPN-клиент для macOS, в котором видно, что происходит с подключением:

- вставляешь ключи от продавца VPN (`vless://` с Reality/TLS и транспортами WS, gRPC, XHTTP; `hysteria2://`; подписки) и выбираешь регион;
- видишь IP и страну до и после подключения;
- меряешь пинг и скорость;
- **выбираешь ползунками, какие приложения идут через VPN**: только выбранные или все, кроме выбранных;
- настраиваешь вид: Liquid Glass (на macOS 26), матовое или сплошное оформление, тема, акцентный цвет, иконка в строке меню, плотность, порядок карточек.

В основе открытое ядро [mihomo](https://github.com/MetaCubeX/mihomo), интерфейс на Swift/SwiftUI.

> **Статус:** этапы 1–6 из 7 сделаны и ждут проверки на маке: импорт ключей и подписок, подключение через ядро mihomo, IP и скорость, выбор программ, ⌘K, горячая клавиша, автозапуск. Kill switch отложен. Релизы собираются по тегу `v*` (этап 7).
> План и этапы: [docs/PLAN.md](docs/PLAN.md). Дизайн: [docs/DESIGN.md](docs/DESIGN.md).

## Установка

Нужен Mac с macOS 14 Sonoma или новее. Настоящий Liquid Glass виден на macOS 26 Tahoe, на 14–15 — матовое стекло.

Пошагово, с первым запуском без подписи Apple, установкой помощника и удалением: [docs/INSTALL.md](docs/INSTALL.md).

Коротко:

1. Скачай `.dmg` из [Releases](https://github.com/aevofounder/vpnforyou/releases) или тестовую сборку `VPNforYou.zip` из **Actions → Build macOS → Artifacts**.
2. Перетащи `VPNforYou.app` в «Программы» и открой. macOS заблокирует первый запуск: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
3. Щит в строке меню → **Добавить ключ или подписку** → вставь ссылку.
4. **Установить помощника** (пароль администратора один раз) → включи VPN.

## Как устроено

- `App/` — приложение в строке меню на SwiftUI: ключи в Связке ключей, экраны, проверка IP и скорости.
- `Packages/VPNCore/` — логика без интерфейса (разбор ключей и подписок, конфиг mihomo, правила для программ, маскировка логов) и помощник `vpnforyou-helper`, который от имени root запускает ядро по командам приложения.
- Ядро [mihomo](https://github.com/MetaCubeX/mihomo) скачивается при сборке фиксированной версии с проверкой SHA-256.

## Сборка из исходников

```sh
brew install xcodegen
xcodegen generate
open VPNforYou.xcodeproj
```

Чтобы подключение работало, в собранное приложение нужно положить помощника и ядро:

```sh
scripts/bundle-extras.sh path/to/VPNforYou.app
```

Тесты логики: `swift test --package-path Packages/VPNCore`.

## Безопасность

В этом репозитории нет и не должно быть настоящих ключей, подписок, адресов серверов и паролей.
Ключи хранятся только на твоём маке, в Связке ключей macOS.
Правила для участников и что делать при утечке: [SECURITY.md](SECURITY.md).
