# VPNforYou

VPN-клиент для macOS, в котором видно, что происходит с подключением:

- вставляешь ключи от продавца VPN (`vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://`, подписки) и выбираешь регион;
- видишь IP и страну до и после подключения;
- меряешь пинг и скорость;
- **выбираешь ползунками, какие приложения идут через VPN**: только выбранные или все, кроме выбранных.

В основе открытое ядро [sing-box](https://sing-box.sagernet.org/), интерфейс на Swift/SwiftUI.

> **Статус:** проект в стадии планирования, приложения ещё нет.
> План и этапы: [docs/PLAN.md](docs/PLAN.md).

## Безопасность

В этом репозитории нет и не должно быть настоящих ключей, подписок, адресов серверов и паролей.
Ключи хранятся только на твоём маке, в Связке ключей macOS.
Правила для участников и что делать при утечке: [SECURITY.md](SECURITY.md).
